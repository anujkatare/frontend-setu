# SETU Frontend

SETU — Project Intelligence frontend for the existing Spring Boot backend.

## Ports
- Frontend: http://localhost:5173
- Backend: http://localhost:8080 (existing backend; do not change it)

## Run
1. Open this folder (the folder containing `package.json`).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:5173

Or double-click `start.bat`.

## Important
This ZIP is intentionally packaged with the project files at the ZIP root. There is **no extra nested project folder**.

Chatbot responses are normalized for display: Markdown heading hashes, bold markers, code fences and Markdown list syntax are converted to clean readable text.

Hero imagery uses public Wikimedia Commons image URLs and therefore requires internet access for those remote photographs.
